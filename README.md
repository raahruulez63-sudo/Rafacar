# Rafacar

## 🚗 Programa de Indicação Automotiva

Bem-vindo ao **Rafacar** - uma plataforma inovadora de indicações automotivas onde você ganha dinheiro indicando clientes para compra de carros e motos.

### 💰 Como Funciona

**Ganhe até R$1.000 indicando clientes!**

1. **Cadastre-se** - Entre para nossa rede de parceiros
2. **Indique** - Envie o contato de quem quer carro, moto, financiamento ou consórcio
3. **Nós atendemos** - Nosso time conduz todo o processo comercial
4. **Receba** - Venda concluída e validada: comissão paga via PIX

### 💵 Tabela de Comissões

| Produto | Comissão |
|---------|----------|
| Moto vendida | R$200 |
| Carro popular | R$500 |
| SUV / Premium | Até R$1.000 |

### ✨ Diferenciais

- ✅ Sem vender
- ✅ Sem investir
- ✅ Sem burocracia
- ✅ Pagamento via PIX

### 🌐 Landing Page

Acesse nossa página de cadastro em `landing_page_chave_pix.html` para se inscrever no programa.

### 📋 Requisitos para Cadastro

- Nome completo
- WhatsApp
- Cidade
- Chave PIX
- Instagram (opcional)
- Preferência de indicação (WhatsApp, Instagram, Amigos/Família, Clientes/Rede profissional)

### 🚀 Comece Agora

1. Clone este repositório
2. Abra o arquivo `landing_page_chave_pix.html` em seu navegador
3. Preencha o formulário de cadastro
4. Comece a indicar clientes e ganhe comissões!
